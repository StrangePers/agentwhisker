# Clearer task statuses for Kitsu

AgentWhisker v0.1.8 for Windows keeps Kitsu’s four core poses. When a task finishes, its row says **Done** and Kitsu returns to Idle if no other task needs a different pose. The legacy `review` value still works in status integrations.

- Unknown or out-of-date statuses use Idle and show an explanation in the task list.
- Completed, unknown, and out-of-date entries stay out of the active task count.
- **Codex + OpenCode** continues to show active work from both sources in the same task list.

Download `AgentWhisker-0.1.8-win-x64.zip`, verify it against `SHA256SUMS.txt`, extract the entire archive, and run `AgentWhisker.exe`. This is a portable, unsigned Windows x64 build.
