# AgentWhisker

Kitsu 是一位陪伴编程智能体的动画桌面伙伴。智能体工作时，她会打字；等待决定或发生错误时，她会改变姿势。

## 开始使用

1. 下载 Windows x64 便携版 ZIP 文件。[下载](https://github.com/StrangePers/agentwhisker/releases/latest)
2. 解压整个 ZIP 文件，然后运行 **AgentWhisker.exe**。
3. 将光标移到 Kitsu 上方，点击齿轮，即可更改**语言**或预览动画。

启动 Codex、Claude Code、OpenCode 或 Qwen Code，然后在 Kitsu 设置的**来源**中选择对应的智能体。也可以连接 JSON 状态文件或使用 Agent Console。

在 Windows 上选择 **Codex + OpenCode**，即可在同一个气泡中查看两个智能体的活动任务。请保持 OpenCode 本地服务运行，以查看正在执行的 Shell 命令。

使用 ChatGPT 登录 Codex 或在 OpenCode 中连接订阅了 Go 的工作区后，即可查看剩余额度及重置时间。

在**空闲动画**中选择**持续播放**或**仅在有事件时**。免费版包含 Kitsu。
