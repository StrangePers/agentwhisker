# Codex and OpenCode side by side

AgentWhisker v0.1.7 for Windows can follow **Codex + OpenCode** at the same time. Open Kitsu’s settings, expand **Source**, and select **Codex + OpenCode**.

- The task bubble shows the active tasks from both sources. Kitsu types while either agent is working and waits when either needs input.
- A running OpenCode service also reports standalone shell commands. AgentWhisker reads their status locally and keeps the command text and output out of the task bubble.
- Short labels under Kitsu fit their text. Longer titles show an ellipsis and the full title on hover.
- The settings header shows the running version.

## Download

Download `AgentWhisker-0.1.7-win-x64.zip`, verify it against `SHA256SUMS.txt`, extract the entire archive, and run `AgentWhisker.exe`. This is a portable, unsigned Windows x64 build. The [Linux and macOS preview](https://github.com/StrangePers/agentwhisker/releases/tag/v0.1.3-preview.1) remains available separately.
