# AgentWhisker для Windows

AgentWhisker показывает, чем занят ИИ-агент, через анимации Kitsu. Она отдыхает между задачами, печатает во время работы, ждёт решения и реагирует на ошибку.

## Первый запуск

1. Скачайте переносимый архив для Windows x64 из GitHub Releases.
2. Распакуйте архив целиком и откройте **AgentWhisker.exe**. Оставьте файлы поставки рядом с EXE.
3. Наведите курсор на Kitsu, откройте шестерёнку и нажмите **«Посмотреть движения»**.

В настройке **«Анимация в покое»** режим **«Постоянно»** выбран по умолчанию. В режиме **«Только при событиях»** Kitsu замирает между задачами и снова двигается при событиях. Щелчки по прозрачному фону проходят к окну под персонажем. Показать, скрыть или закрыть приложение можно из трея.

## Свой источник задач

Выберите файл статуса в настройках или передайте путь при запуске.

```powershell
.\AgentWhisker.exe --status-file=C:\example\status.json
```

Файл может содержать `{"state":"running","title":"Сборка проекта"}`. Поддерживаются `idle`, `running`, `waiting` и `failed`. Для Agent Console предусмотрен локальный мост. Автономный запуск не требует Agent Console и Python. [Интеграция Agent Console](../README.md#agent-console).

В бесплатную поставку входит Kitsu. Дополнительные персонажи устанавливаются из отдельного файла `.whiskerpack` через настройки. [Условия использования графики](../ARTWORK.md).
