# Project folders from Codex tasks

On Windows, click a Codex task marked **Open project folder** in Kitsu’s task list to open its local working directory. Each row uses its own session metadata. AgentWhisker checks the session and folder again when you click.

| Source | Task action in this release |
|---|---|
| Codex | Opens the available local project folder for a running, waiting or failed task. |
| Agent Console | Opens the corresponding Console task. |
| OpenCode, Claude Code, Qwen Code, T3Code | Shows task status. |
| JSON status file | Shows the supplied status and retains support for Agent Console task identifiers. |
