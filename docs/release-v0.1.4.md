# AgentWhisker v0.1.4 for Windows

On first launch, Kitsu offers local Codex, Claude Code, OpenCode, and Qwen Code sources when she finds them. Pick one to follow, choose a source manually, or keep her as a desktop companion. Existing profiles continue with their saved source. Agent Console launches directly into its managed session.

The Source section explains when to start a session or check an unreadable source. You can retry a connection and choose a JSON status file using the Windows file picker. Claude Code task tracking works independently of subscription limits.
