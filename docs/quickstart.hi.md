# AgentWhisker

Kitsu कोडिंग एजेंटों के लिए ऐनिमेटेड डेस्कटॉप साथी है। एजेंट के काम करते समय वह टाइप करती है। निर्णय की प्रतीक्षा या त्रुटि होने पर उसकी मुद्रा बदल जाती है।

## शुरू करें

1. Windows x64 के लिए पोर्टेबल ZIP डाउनलोड करें। [डाउनलोड](https://github.com/StrangePers/agentwhisker/releases/latest)
2. पूरी ZIP फ़ाइल निकालें और **AgentWhisker.exe** चलाएँ।
3. Kitsu पर कर्सर ले जाएँ और गियर पर क्लिक करके **भाषा** बदलें या ऐनिमेशन देखें।

**निष्क्रिय अवस्था का ऐनिमेशन** में **लगातार** या **केवल इवेंट होने पर** चुनें। JSON स्थिति फ़ाइल या Agent Console ब्रिज से कनेक्ट किया जा सकता है। मुफ़्त डाउनलोड में Kitsu शामिल है।
