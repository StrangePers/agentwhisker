# AgentWhisker v0.1.11 for Windows

Kitsu eases between poses. The counter rolls upward when a task starts and downward when one finishes. Open the task bubble to see rows slide into place. Completed rows fade as the panel shrinks around the remaining work. When space above Kitsu is tight, the panel opens beside her so a second task can fit.

The new transitions respect the system’s reduced-motion preference. The Idle animation setting still controls whether Kitsu moves between tasks.

Download AgentWhisker-0.1.11-win-x64.zip and SHA256SUMS.txt. Compare the ZIP’s SHA-256 with the checksum file, extract the entire archive, and run AgentWhisker.exe. Open settings to check the version.
