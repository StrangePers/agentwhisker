# AgentWhisker v0.1.1

AgentWhisker now speaks **English**, **Spanish**, **Simplified Chinese**, and **Hindi**. Settings, task and usage panels, character previews, tray menus, and app messages follow the selected language.

The app follows your system language when possible and falls back to English. Hover over Kitsu, open the gear menu, and pick **Language** to switch. Task titles and messages are displayed as supplied by their connected sources.

The [project website](https://strangepers.github.io/agentwhisker/) is also available in all four languages.

Download **AgentWhisker-0.1.1-win-x64.zip**, extract the entire ZIP, and run **AgentWhisker.exe**. The portable build includes Kitsu and was tested on Windows 11 x64. The executable is unsigned. Verify the download against **SHA256SUMS.txt**.
