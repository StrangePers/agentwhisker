# AgentWhisker v0.1.3

See remaining subscription usage and reset times for **Codex** and **OpenCode Go**. Select the agent under **Source**, then open the limits panel next to Kitsu. Codex uses the ChatGPT account signed in through its local CLI. OpenCode uses the Go subscription connected to its local service.

- The panel shows the window with the least remaining usage. Expand it to see the other windows and the last checked values.
- Settings open beside Kitsu and switch sides near a monitor edge. Kitsu, the gear, and the task count stay in place.
- Set **Limits button** to **Hide** if you prefer to keep the control off the desktop. Agent Console can still supply its own limits and credits.

Download **AgentWhisker-0.1.3-win-x64.zip**, extract the entire archive, and run **AgentWhisker.exe**. Verify the archive against **SHA256SUMS.txt**. This portable, unsigned Windows x64 build includes Kitsu. [Project website](https://strangepers.github.io/agentwhisker/).
